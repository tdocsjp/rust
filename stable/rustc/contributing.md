# `rustc` への貢献（要約）

**コンパイラへの貢献:**

rustc プロジェクトは貢献を歓迎しています。コンパイラの内部構造、ビルド方法、始め方についての詳しいガイドは [rustc Developer Guide](https://rustc-dev-guide.rust-lang.org/) を参照してください。

**ドキュメントへの貢献:**

この rustc book 自体に貢献するには、ソースコードは Rust のメインリポジトリ内の [`src/doc/rustc`](https://github.com/rust-lang/rust/tree/HEAD/src/doc/rustc) にあります。GitHub から直接編集を提案できます。
