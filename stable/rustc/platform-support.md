# Platform Support（要約）

## 目的

このページは、「ターゲットタプル」文字列で識別される様々なターゲットプラットフォームに対する Rust のサポート状況を記録しています。プラットフォームは、保証やサポートレベルの異なる3つの Tier (階層) に分類されます。

## Tier 制度

**Tier 1（ホストツール付き）**
- 標準ライブラリを完全にサポートし、動作することが保証される
- 各ターゲット向けに公式のバイナリリリースがビルドされる
- 変更ごとにビルド・テストが通ることを自動テストで保証する
- そのターゲット上で `rustc` と `cargo` をネイティブに実行でき、開発プラットフォームとして使える
- 例: `aarch64-apple-darwin`、`x86_64-pc-windows-msvc`、`aarch64-unknown-linux-gnu`

**Tier 1**
- 公式バイナリリリースで動作することが保証される
- 変更ごとにビルド・テストが通ることを自動テストで保証する
- 現時点では、すべての Tier 1 ターゲットはホストツールのサポートも持つ

**Tier 2（ホストツール付き）**
- ビルドできることが保証される（正しく動く出力を生成するとは限らない）
- 公式の標準ライブラリバイナリが提供される
- そのターゲット上でホストツールをネイティブに実行できる
- 標準ライブラリを完全にサポートする
- 品質管理はやや緩く、バグがある可能性がある。パッチは歓迎される
- これらのターゲット向けにドキュメントがビルドされない場合がある

**Tier 2（ホストツールなし）**
- 標準ライブラリ（または `core` ライブラリのみ）付きでビルドできることが保証される
- 自動ビルドにより、コンパイル対象として使えることが保証される
- 必ずしもテストが実行されるわけではない
- 標準ライブラリのサポートレベルは様々: 完全（✓）、`no_std` のみ（*）、作業中（?）

**Tier 3**
- Rust のコードベースにはサポートがあるが、自動的にビルド・テストされない
- 公式ビルドはない
- 動くかどうかは保証されない
- 品質管理の保証は最も緩い
- 標準ライブラリのサポートレベルは様々

## 完全なターゲット一覧の探し方

コンポーネントの利用可能状況は https://rust-lang.github.io/rustup-components-history/ で追跡されています。

各 Tier のセクションには、ターゲットタプル、標準ライブラリのサポート状況、プラットフォームの説明を含む詳細な表があります。個々のターゲット（`x86_64-pc-windows-msvc` など130以上）については、[doc.rust-lang.org](https://doc.rust-lang.org/stable/rustc/platform-support.html) の該当ページを参照してください。
