# 既知の問題（要約）

このページは、**target-feature フラグ**に関する注意点を記録しています。

## 主な問題: ターゲットフィーチャーの混在による ABI の不一致

主な既知の問題は、**異なる target-feature 設定でコンパイルされたコードを混在させると、未定義動作やクラッシュが起こる**ことです。

### 問題の核心

- `-C target-feature` フラグでコンパイルしても、標準ライブラリや依存クレートが同じフィーチャーで自動的に再コンパイルされる**わけではない**
- つまり、自分のコードが標準ライブラリとは異なる呼び出し規約を使ってしまい、クラッシュにつながる可能性がある

### 例: x86/x86-64 での `+soft-float` と `-sse`

SSE を無効化（ソフトウェアによる浮動小数点エミュレーションを使用）すると:

- 自分のコードはソフトウェアでエミュレートされた浮動小数点演算を使う
- しかし Rust のコアライブラリ（`std::f32`、`std::f64`）は、浮動小数点引数に **SSE レジスタ（`xmm`）**を期待してコンパイルされている
- 結果: **ABI の不一致とセグメンテーション違反**

### 推奨事項

未定義動作を避けるため、設定を混在させるのではなく、**標準ライブラリとクレートを含むすべてのコードを、一貫したターゲットフィーチャーの組み合わせでビルドしてください**。
